Banking Survey and Analytics

Project Overview

This project collects customer feedback about banking services and displays customer satisfaction through an analytics dashboard.

Technologies Used

- Python
- FastAPI
- SQLite
- HTML
- CSS
- JavaScript

Features

- Customer satisfaction survey
- Customer ID validation
- Store survey responses in SQLite
- Analytics dashboard
- Customer satisfaction statistics
- Frontend and backend integration

Project Structure

- backend/
  - main.py
  - database.py
  - frontend/
    - index.html
    - survey.html
    - analytics.html
    - style.css

How to Run

1. Open the project in VS Code.
2. Open the backend folder in the terminal.
3. Run: "python -m uvicorn main:app --reload"
4. Open "frontend/index.html" using Live Server.
5. Use the survey and analytics pages.

Project Objective

To understand customer satisfaction through survey responses and provide useful analytics for improving banking services.
